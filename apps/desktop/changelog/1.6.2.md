# What's new in v1.6.2

## Shiny new things

- Added BYOK support for OpenAI-compatible custom routers, including ZenMux.
- Added ZenMux model discovery with searchable, scrollable, recently used model selection.

## Improvements

- AI chat and summary generation now use the configured BYOK provider when available.
- Article summaries now stream partial BYOK output into the summary card as it is generated.
- BYOK summary generation now receives the same in-app treatment as the built-in Pro AI path.

## No longer broken

- Fixed chat send availability when BYOK is configured.
- Fixed BYOK model dropdown behavior after switching providers.
